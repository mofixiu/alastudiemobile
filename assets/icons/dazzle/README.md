# Dazzle Line Icons

Bundled SVGs selected from the [Dazzle Line Icons collection on SVG Repo](https://www.svgrepo.com/collection/dazzle-line-icons/). These files are kept locally so app icons work offline. Runtime tinting is applied by the app.

The source collection and individual icons may carry their own license terms; see each source icon page and [SVG Repo licensing](https://www.svgrepo.com/page/licensing) before redistributing the app.
